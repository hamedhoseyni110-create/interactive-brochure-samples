# Interactive Brochure Samples

Two self-contained, single-file interactive brochure samples (Persian RTL, zero external requests, embedded fonts):

- [`ramin-burger/`](ramin-burger/) — Ramin Burger interactive brochure
- [`cafe-nozhe/`](cafe-nozhe/) — Café Nozhe interactive brochure

Open the `index.html` in each folder (or visit the GitHub Pages site) to view them.

Built with the Gemini Canvas hybrid pipeline: Canvas generated the base, then the code was polished by hand (RTL fixes, performance, offline self-containment).
